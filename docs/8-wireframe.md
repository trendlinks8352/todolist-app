## 와이어프레임 개요

**목적**: 사용자 여정, UI 컴포넌트 배치, 네비게이션 흐름을 ASCII 기반으로 명확히 표현합니다.

**범위**:
- MVP 1차 릴리즈에 포함된 7개 주요 화면
- 모바일-퍼스트 반응형 레이아웃 (375px / 768px / 1024px 브레이크포인트)
- 화면 간 이동 흐름 및 상호작용
- 각 화면의 핵심 기능과 유효성 검사 규칙

**설계 원칙**:
- Mobile-first 반응형 웹 접근
- 직관적 네비게이션 (뒤로가기, 로그아웃 등 일관성)
- 모든 주요 기능(UC-01~08, UC-12~13)을 포함
- 에러 메시지 및 성공 피드백 표시
- 접근성 고려 (터치 타겟 최소 44px)

## 주요 디자인 결정

### 1. 모달 vs. 페이지

- **WF-04 (할일 등록·수정)**: 모달 선택
  - 이유: 빠른 진입 및 취소, 목록 보존
- **WF-05 (카테고리)**: 페이지 선택
  - 이유: 목록이 많을 수 있음, 여러 카테고리 비교 필요

### 2. 기본 카테고리 표시

- 수정/삭제 불가 상태를 잠금(🔒) 아이콘으로 명확히 표시
- BR-08, BR-09 준수

### 3. 필터 배치

- 할일 목록 상단에 고정 필터 바
- 사용자가 쉽게 조건 변경 가능
- DC-08, DC-09 필터 제약 반영

### 4. 확인 모달

- 삭제, 회원 탈퇴 같은 중요 동작에만 사용
- 명확한 경고 메시지 포함
